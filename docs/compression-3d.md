# เครื่องกด 3D ในห้องทดลองแรงกดทับ

- เปิดจากหน้าปก → ไปหน้าทดสอบ → ห้องความต้านทานแรงกดทับ
- ฉาก Three.js ใช้ WebGL canvas เดียว แบ่งมุมเปรียบเทียบก่อนกดและขณะรับแรงกด
- รองรับวัสดุ 5 ชนิดเดิม ลากหรือใช้ลูกศรซ้าย/ขวาเพื่อหมุนทั้งสองมุมพร้อมกัน และใช้ปุ่มมุมตรง/มุม 3D เพื่อคืนมุมมาตรฐาน
- คงปุ่มเริ่มทดสอบ การเลือกผล การเตือนผลที่ยังไม่บันทึก และเปิดให้เด็กบันทึกสิ่งที่ตนสังเกตเอง
- การเข้าหาวัสดุใช้ 700 ms แล้วกด 3 วินาที โดยแผ่นกดเคลื่อนตามผิววัสดุตลอดช่วงยุบ
- เมื่อกด “ทดสอบอีกครั้ง” แท่นด้านขณะรับแรงกดจะยกกลับและวัสดุคืนความหนาเป็นเวลา 650 ms ก่อนแท่นเลื่อนลงมาเริ่มรอบใหม่

## เงื่อนไขและชุดข้อมูลอ้างอิง

- ชิ้นวัสดุ 10 × 10 ซม. หนาเริ่มต้น 5 มม.
- แรงกด 200 นิวตัน หรือความดัน 20 kPa และกดค้าง 3 วินาที
- ใช้ค่าการยุบ ความหนาขณะกด และผลจำแนกของวัสดุทั้ง 5 ชนิดจากชุดข้อมูลที่ผู้ใช้ให้ไว้ใน `COMPRESSION_MATERIAL_RESULTS`
- การบีบในฉาก 3D ใช้สเกลภาพตามผลจำแนกเดียวกับภาพตัวเลือก เพื่อให้เด็กมองเห็น “ยุบเล็กน้อย” และ “ยุบมาก” ได้ชัด ส่วนตัวเลขมิลลิเมตรยังเก็บตามชุดข้อมูลอ้างอิง
- วัสดุที่กำหนดว่า “ไม่เห็นการยุบ” คงความสูงเดิมและเว้นช่องว่างเล็กน้อยใต้แท่น เพื่อป้องกันภาพอุปกรณ์ซ้อนกับผิววัสดุ
- ตารางบันทึกผลแสดงค่าจากข้อมูลอ้างอิงแยกจากผลที่เด็กเลือกสังเกต และไม่ใช้ข้อมูลอ้างอิงตัดสินหรือแทนคำตอบของเด็ก

ค่าชุดนี้เป็นข้อมูลอ้างอิงที่กำหนดให้ Simulation และแอปไม่ได้ตรวจสอบความถูกต้องทางห้องปฏิบัติการโดยอิสระ ฉาก 3D เป็นภาพแทนผลตามค่าเหล่านี้ ไม่ใช่ตัวคำนวณฟิสิกส์

## การทำงานและทรัพยากร

- `CompressionPress3D.tsx` โหลดโมดูล 3D เฉพาะเมื่อเปิดห้อง และใช้ SVG เดิมระหว่างโหลดหรือเมื่อ WebGL ใช้งานไม่ได้
- `compression-scene.ts` สร้างโมเดลด้วยโค้ด ไม่ดาวน์โหลดโมเดลหรือพื้นผิวจากบริการภายนอก และไม่เรียก AI ขณะเล่น
- วาดเฟรมเมื่อกดทดลอง เปลี่ยนวัสดุ เปลี่ยนมุม หรือปรับขนาดเท่านั้น หยุดวาดเมื่อแท็บถูกซ่อน จำกัดความละเอียดที่ 1.75 เท่าของขนาด CSS และคืนทรัพยากรเมื่อออกจากห้อง
- เคารพ `prefers-reduced-motion`: แสดงท่าปลายทางโดยไม่เคลื่อนไหว แต่คงเวลาทดลองเดิม
- คำนวณตำแหน่งด้วย `compressionPose` ใน `compression.ts` และทดสอบค่าข้อมูล เงื่อนไข การสัมผัส การยุบต่อเนื่อง และการไม่ยุบทะลุฐานใน `compression.test.ts`

อ้างอิงวิธีจัดการ canvas และทรัพยากร: [Three.js responsive rendering](https://threejs.org/manual/en/responsive.html), [Three.js cleanup](https://threejs.org/manual/en/cleanup.html)

## ตรวจสอบ

```text
pnpm lint
pnpm test
pnpm build
```
